# Task Management REST API

A lightweight RESTful API for managing tasks built with **Python**, **Flask**, and **MongoDB Atlas**.

---

## Features

- **Create Task (`POST`)**: Add a new task with title, description, due date, and status.
- **Read All Tasks (`GET`)**: Retrieve all tasks.
- **Read Task by ID (`GET`)**: Retrieve a single task by its MongoDB `ObjectId`.
- **Update Task (`PUT`)**: Modify an existing task.
- **Delete Task (`DELETE`)**: Remove a task by its ID.

---

## Tech Stack

- **Framework**: Flask
- **Database**: MongoDB Atlas
- **ODM / Driver**: Flask-PyMongo, PyMongo, dnspython
- **Environment Management**: python-dotenv

---

## Prerequisites

- [Python 3.10+](https://www.python.org/downloads/)
- A free [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) cluster and database user
